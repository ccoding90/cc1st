# 🦖 스톤몬스터 (Stone Monster) 기획서 — 데모 1단계 「태초마을」

> 경로: `/stone-monster` · 코드: `src/components/StoneMonsterGame.jsx`, `src/components/stonemon/`
> (아래 50종 표와 상성표는 `stonemon/data.js` 에서 자동 생성)

## 1. 콘셉트
- **장르**: 몬스터 수집·육성 RPG (2D 도트, 탑뷰 마을 탐험 + 턴제 배틀)
- **세계관**: 원시 시대와 몬스터 세계가 결합된 판타지. 돌알에서 태어나 서로를 잡아먹으며 진화하는 존재 ─ 스톤몬스터.
- **모티브**: 약육강식 · 약자멸시 · 적자생존
- **핵심 차별점**: 레벨/경험치가 없다. 오직 **포식**으로만 강해지고, 진화는 **끝이 없다**.

## 2. 핵심 시스템
### 2-1. 포식 (잡아먹기)
배틀에서 이기면 쓰러진 상대를 **포식 / 봉인(야생만) / 그냥 둔다** 중 선택. 포식하면 아래 요소가 흡수된다.

| 흡수 요소 | 규칙 |
|---|---|
| 능력치 | 상대 실전 능력치의 일정 비율 (야생 12% · 트레이너 15% · 대전 20% · 보스 22% · 동료 바치기 25%) |
| 속성 유전자 | 상대 핵 속성 +(1+등급), 대전·보스 +2 추가, 상대가 품은 유전자의 절반 |
| 특성 | 야생: 1개 / 트레이너·대전·보스: 상대 특성 전부 (+1Lv, 최대 10) |
| 기술 | 상대 기술 중 1개 선택해 습득 (4개 초과 시 하나 잊음) |
| 회복 | 최대 체력 30% 회복 |

`대식가` 특성은 흡수량을 Lv당 +15% 늘린다.

### 2-2. 무한 변이 진화
- 변이 단계 n 에 필요한 유전자 총량 = n(n+2) → 3, 8, 15, 24, 35, 48 … (상한 없음)
- 단계가 오를 때마다 전 능력치 +5% 와 **변이 연출 + 진화 결과창**
- **외형 변이**: 핵 속성이 아닌 유전자가 2/8/20 이상이면 해당 부위가 1/2/3단계로 자란다

| 유전자 | 외형 변이 |
|---|---|
| 🌪️ 바람 | 피막 날개 → 큰 날개 → 네 장의 날개 |
| ⚡ 번개 | 등의 번개 가시 · 스파크 · 노란 눈 |
| 🔥 화염 | 꼬리 불꽃 → 불꽃 갈기 → 전신 불길 |
| 💧 물 | 등지느러미 → 꼬리지느러미 → 물방울 |
| ❄️ 얼음 | 서리 결정 → 칼날 결정 → 빙하 갑옷 |
| 🪨 대지 | 바위 판 → 돌뿔 → 암반 등껍질 |
| ☠️ 독 | 독반점 → 독가시 → 흘러내리는 독 |
| 🦴 원시 | 뼈 가시 → 긴 뼈 가시 → 뼈 왕관 |

- **이름 변이**: `[가장 많이 흡수한 속성 접두] + [본체 + 가장 많이 먹은 종 합성] + 단계` 예) 티랑이 + 프테리 → **천공 티랑테리**
- 유전자 3 이상 흡수한 속성은 보유 속성이 되어 그 속성 기술 자속 보정(×1.25)과 **그 속성 공격 내성(×0.85)** 을 얻는다 (번개를 먹으면 번개에 강해진다)

### 2-3. 영구 소실 (Permadeath)
- 내 스톤몬이 쓰러지면 상대에게 **먹혀서 영원히 사라진다** (상대는 그만큼 강해짐)
- 동료(최대 4)가 모두 먹히면 **처음부터 다시** (도감·무덤·이름은 유지)
- 무덤(기록)에 먹힌 스톤몬의 이름·전투력·포식 수·사인이 남는다

### 2-4. 포식의 제단 (플레이어 대전)
- 대장 스톤몬의 **그림자**(능력치 스냅샷)를 제단에 등록 → 다른 플레이어가 AI 대전으로 도전 (Firestore `stonemon_arena`, `stonemon_results`)
- 도전자가 이기면 그림자를 **포식**(흡수율 20% + 유전자 보너스) → 그림자는 제단에서 사라짐
- 도전자가 지면 **도전자의 스톤몬이 먹힘** (영구 소실)
- 그림자가 방어에 성공하면 주인에게 뼈조각 +40 · 능력치 상승 보상 (그림자가 먹혀도 본체는 무사)
- 실제 플레이어가 부족하거나 오프라인이면 떠돌이 사냥꾼 그림자(내 전투력 0.8~1.35배)가 채운다

### 2-5. 수집
- 봉인석으로 쓰러뜨린 야생 스톤몬을 동료로 봉인 (등급별 성공률 95/75/55/30%, 우두머리 ×0.6)
- 동료는 **먹이로 바치기**로 다른 동료에게 먹일 수 있다 (흡수율 25%) — 수집이 곧 성장 재료
- 도감 50종: 발견(실루엣) → 포식/봉인(상세 정보)

## 3. 배틀
- 턴제 1:1, 명령: 싸운다(기술 4) / 스톤몬(교체) / 가방 / 도망(야생만)
- 피해 = (위력 × 공격 / 방어) × 0.15 + 2 → 자속 ×1.25 · 상성 ×1.6/×0.6 · 급소 ×1.5 · 난수 0.85~1
- 상태이상: 화상 / 마비 / 중독 / 빙결 (같은 속성은 면역)
- 특성 18종 · 기술 47종 (8속성)

| 공격 속성 | 효과 굉장 (×1.6) |
|---|---|
| 🦴원시 | — (중립) |
| 🔥화염 | 얼음, 독 |
| 💧물 | 화염, 대지 |
| ⚡번개 | 물, 바람 |
| 🌪️바람 | 독, 대지 |
| 🪨대지 | 번개, 화염 |
| ❄️얼음 | 바람, 대지 |
| ☠️독 | 물, 원시 |

## 4. 1단계 태초마을 구성
| 장소 | 내용 |
|---|---|
| 🏠 집 | 엄마 · 스톤몬 전체 회복 · 자동 저장 |
| 🔬 고돌 박사 연구소 | 스타팅 선택(티랑이/트톱이/브라키) · 공략 조언 · 도감 현황 |
| 🍖 원시 상점 | 생고기(50% 회복) 30 · 통구이(100%+상태 치료) 90 · 봉인석 50 (화폐: 뼈조각) |
| 🗿 포식의 제단 | 플레이어 대전 · 그림자 등록 |
| 🌿 북쪽 풀숲 | 야생 16종 출현 (내 대장 전투력의 0.5~0.85배, 7% 확률로 우두머리 ×1.3) |
| 🏛️ 태초의 신전 | 족장 우가 (보스 3마리 · 이번 생 포식 5회 이상 필요) |

**퀘스트 흐름**: 눈을 뜸 → 엄마 → 연구소에서 돌알 선택·부화 → 북쪽 풀숲에서 야생 프테리와 튜토리얼 배틀 → **첫 포식 → 바람 유전자 흡수 → 날개 변이** → 다음 행동 3택(사냥 / 제단 대전 / 박사에게 보고) → 사냥꾼 돌쇠·누리·바위 → 족장 우가 → 1단계 클리어

**트레이너**: 꼬마 사냥꾼 돌쇠(랩티 ★95) · 채집꾼 누리(메가네 ★115, 콤피 ★125) · 사냥꾼 바위(파키 ★165, 디메트 ★180) · 족장 우가(스테고 ★340, 돌돌이 ★380, 딜로 ★420)

**밸런스 시뮬레이션** (스타팅 1마리로 야생 사냥 → 트레이너 → 보스, 2판마다 회복, 1.0배 초과 상대는 도망): 보스 도달 시 평균 ★425 · 포식 13회. 야생 사냥 중 사망률 티랑이 ~17% / 트톱이 ~2% / 브라키 ~10%.
